# Particle Swarm Optimization (PSO)

## Description

This project implements the Particle Swarm Optimization (PSO) algorithm using Python to optimize the Sphere Function.

The program calculates the best position and best fitness value, then visualizes the optimization process using a convergence graph.

## Features

- Particle Swarm Optimization (PSO)
- Sphere Function optimization
- Best Position calculation
- Best Fitness calculation
- Convergence graph visualization

## Requirements

- Python 3.x
- NumPy
- Matplotlib

Install the required libraries:

```bash
pip install numpy matplotlib
```

## Run

```bash
python main.py
```

## Output

The program displays:

- Best Position
- Best Fitness
- PSO Convergence Graph
